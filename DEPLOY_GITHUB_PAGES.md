# Publish NABD with GitHub Pages

1. Create a **public** GitHub repository named `nabd-health`.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages deployment to finish. The public URL will usually be `https://YOUR-USERNAME.github.io/nabd-health/`.
7. Open the URL in a private/incognito window and test the language selector, accessibility controls, guided form, and mobile layout.

GitHub Pages is static hosting. This version uses no server-side API and does not contain a real AI model. Never put API keys or private credentials in this repository.
