# Security and privacy notes

- Do not commit API keys, passwords, tokens, private health records, or personal identifiers.
- The current prototype is static and does not require credentials or a backend.
- Do not add client-side secrets. Any future third-party API integration must keep credentials server-side.
- Use fictional data when demonstrating the prototype.
- Do not enter names, addresses, contact details, or other identifying or sensitive information.
- Before public deployment, conduct a security and privacy review, dependency review, and accessibility review.
- Report a suspected security issue privately to the project maintainer rather than publishing sensitive exploit details.
