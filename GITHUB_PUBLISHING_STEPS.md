# Publish NABD to GitHub

1. Sign in to GitHub and choose **New repository**.
2. Repository name: `nabd-one-step-ahead-of-health`.
3. Set visibility to **Public** if the competition requires a public code repository.
4. Do not initialize with a README, license, or .gitignore because these are already included.
5. Extract this project ZIP on your computer.
6. Upload the contents of the `NABD_Final_Submission_English` folder (not the parent folder) to the new repository.
7. Confirm that `index.html`, `nabd-health-hero.png`, `README.md`, `SUBMISSION_BRIEF.md`, and `DEMO_SCRIPT.md` are visible.
8. Open `index.html` from the repository and check that the hero image path is correct. For a public website, enable GitHub Pages from repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
9. Copy the public repository URL into the competition submission form.

Never upload API keys, passwords, personal information, or real health records. The current prototype does not need an API key.
